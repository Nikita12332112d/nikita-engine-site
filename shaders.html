Shaders

A shader is a small program the graphics card runs for every vertex and every pixel it draws. It is where the look of a game is decided, and it is the fastest code you will ever write.

What a shader is

Everything on screen is drawn by a shader — the engine ships defaults you never see. Writing your own replaces the default for one material, and nothing else changes.

A shader runs in two stages. Vertex runs once per corner of a mesh and can move geometry around. Fragment runs once per pixel that ends up covered and decides what colour it is. Both run for millions of items at once, which is why they are fast and why they cannot see each other's results.

The language is not NikaScript. Shaders are written in a C-like language that compiles to GPU code: braces, semicolons, and types declared before names. Everything on this page uses that language. Shader files carry the .nikashader extension.

The shader editor

The editor lives at the bottom of the window, beside the script editor. The quickest way to open it is to give a node a shader material.

Select a node that draws something — a Sprite2D, a MeshInstance3D, a ColorRect.

In the Inspector find Material (for 3D, Surface Material Override → 0) and choose New ShaderMaterial.

Click the material, then on its Shader property choose New Shader. Pick the mode — CanvasItem for 2D, Spatial for 3D — and give it a name.

The shader editor opens with a starting file. Edit it and the result appears in the viewport as you type; there is no compile step and nothing to press.

What the panel gives you

Errors appear underlined in the code and spelled out at the bottom, with the line number. A shader that fails to compile leaves the last working version on screen, so a typo never blanks your scene.

Uniforms you declare show up in the Inspector under the material as soon as you save, with sliders and colour pickers where the hint asks for them. That is the fastest way to find good values: write the uniform, then drag.

Shaders as files

A shader made this way lives inside the scene. To reuse it, save it as a file: on the Shader property choose Save As, or create one up front in the FileSystem dock with right-click → Create New → Shader. Files end in .nikashader, are plain text, and read well in a diff.

The node graph

If code is not how you want to work, choose New VisualShader instead of New Shader. It opens a node graph where the same operations are boxes you wire together, and it produces the same GPU program. The two are not interchangeable per file: a shader is either text or a graph.

Anatomy of a shader

The shortest useful one, in full:

shader_type canvas_item;

uniform vec4 tint : source_color = vec4(1.0);

void fragment() {
	COLOR = texture(TEXTURE, UV) * tint;
}

Four things are worth naming.

PartWhat it does
shader_typeMust be the very first line. It decides which built-ins and functions exist.
uniformA value from outside — the Inspector or your code. Constant for the whole draw.
fragment()Runs per pixel. vertex() and light() are the other two entry points.
UPPERCASEBuilt-ins. Some are inputs you read, some are outputs you write, a few are both.

Types are the usual GPU set: float, int, bool, vec2, vec3, vec4, mat2–mat4, and sampler2D for textures. There is no implicit conversion, so 1 and 1.0 are not the same thing and mixing them is an error.

Shader types

The first line picks one of six. Most work uses the first two.

shader_typeDraws
canvas_itemEverything 2D: sprites, controls, tilemaps. The default for a new 2D material.
spatialEverything 3D: meshes, and the material properties that feed lighting.
particlesMoves particles on the GPU. Writes positions and velocities, not colour.
skyThe background of a 3D scene, evaluated per direction rather than per pixel of a surface.
fogDensity and colour inside a FogVolume.
texture_blitCopies one texture to another. Rarely written by hand.

Uniforms

A uniform is a knob. Declare it, and it appears in the Inspector under the material.

uniform float strength : hint_range(0.0, 1.0) = 0.5;
uniform vec4 glow : source_color = vec4(1.0, 0.4, 0.1, 1.0);
uniform sampler2D mask : hint_default_white;
uniform sampler2D bumps : hint_normal;

The part after the colon is a hint. It changes how the value is presented and, for colours, how it is interpreted.

HintEffect
source_colorShows a colour picker and converts from sRGB. Use it on every colour, or your colours come out wrong.
hint_range(min, max)A slider instead of a number field. A third argument sets the step.
hint_default_whiteAn unset texture reads as white rather than black — the right default for a multiplier.
hint_default_blackThe opposite, for something added on top.
hint_normalMarks the texture as a normal map.
filter_nearestNo smoothing between texels. The one you want for pixel art.
repeat_disableClamps at the edges instead of tiling.
source_color is not decoration. Colours picked in the Inspector are sRGB, while the shader works in linear space. Without the hint the engine hands the value over unconverted and everything looks washed out or too dark, in a way that is easy to blame on the lighting instead.

render_mode

One optional line, straight after shader_type, that changes how the surface is drawn rather than what colour it is.

shader_type spatial;
render_mode unshaded, cull_disabled, blend_add;
ModeEffect
unshadedIgnore lights entirely; ALBEDO goes straight to the screen. Right for UI, holograms and effects.
cull_disabledDraw both sides of every face. Needed for flat things like leaves and cloth.
cull_frontDraw only back faces. The old trick for outlines built from an inflated hull.
blend_addAdd to what is behind instead of covering it. Fire, sparks, glow.
blend_mixThe normal alpha blend, and the default.
depth_draw_neverDo not write depth. Usual for transparent surfaces that overlap each other.
shadows_disabledThe surface casts no shadow.
vertex_lightingLight per vertex instead of per pixel. Cheaper, and deliberately retro.

Spatial shaders accept 23 modes in total and canvas_item accepts 5; the ones above are the ones that come up. Modes are comma-separated on a single line.

Driving it from code

Uniforms are readable and writable from NikaScript, which is how effects get animated or tied to gameplay.

from Node3D

let material := ShaderMaterial.new()

fn _ready():
	material.shader = load("res://water.nikashader")
	material.set_shader_parameter("wave_height", 0.35)
	$MeshInstance3D.material_override = material

fn dissolve() -> void:
	for i in range(60):
		material.set_shader_parameter("amount", float(i) / 60.0)
		await get_tree().process_frame

The name is the uniform's name as a string. A typo fails silently — the parameter simply does not exist — so check the spelling first when nothing happens.

For a value that differs per object while the material is shared, declare it instance (instance uniform vec4 tint;) and set it with set_instance_shader_parameter() on the node. That avoids one material per object.

Scrolling texture

Moving the coordinate instead of the object. Good for water, conveyor belts, and skies on a 2D backdrop.

shader_type canvas_item;

uniform vec4 tint : source_color = vec4(1.0, 1.0, 1.0, 1.0);
uniform vec2 scroll = vec2(0.1, 0.0);

void fragment() {
	vec2 moving_uv = UV + scroll * TIME;
	COLOR = texture(TEXTURE, moving_uv) * tint;
}

TIME counts seconds since the game started, so multiplying by it turns a direction into a speed. The texture must be set to repeat or the edge will smear — that is the texture's import setting, not the shader's job.

Outline

Draws a border around whatever is opaque in a sprite, by asking the four neighbouring pixels whether anything is there.

shader_type canvas_item;

uniform vec4 line_color : source_color = vec4(0.0, 0.0, 0.0, 1.0);
uniform float thickness : hint_range(0.0, 8.0) = 2.0;

void fragment() {
	vec4 base = texture(TEXTURE, UV);
	if (base.a > 0.0) {
		COLOR = base;
	} else {
		vec2 offset = TEXTURE_PIXEL_SIZE * thickness;
		float around =
			texture(TEXTURE, UV + vec2(offset.x, 0.0)).a +
			texture(TEXTURE, UV - vec2(offset.x, 0.0)).a +
			texture(TEXTURE, UV + vec2(0.0, offset.y)).a +
			texture(TEXTURE, UV - vec2(0.0, offset.y)).a;
		COLOR = vec4(line_color.rgb, line_color.a * min(around, 1.0));
	}
}
The sprite needs room for the outline. A shader can only colour pixels the sprite already covers, so a border drawn at the very edge of the texture has nowhere to go. Leave a few transparent pixels of margin in the image, or the outline appears on three sides.

Rim light

Brightens the silhouette where a surface turns away from the camera. It reads as a highlight and separates an object from its background almost for free.

shader_type spatial;

uniform vec4 base_color : source_color = vec4(0.15, 0.15, 0.20, 1.0);
uniform vec4 rim_color : source_color = vec4(0.545, 0.361, 0.965, 1.0);
uniform float rim_power : hint_range(0.5, 8.0) = 3.0;

void fragment() {
	ALBEDO = base_color.rgb;
	float facing = clamp(dot(NORMAL, VIEW), 0.0, 1.0);
	EMISSION = rim_color.rgb * pow(1.0 - facing, rim_power);
}

NORMAL points out of the surface and VIEW points at the camera. Their dot product is 1 straight on and 0 at the edge, so 1.0 - facing is the silhouette. The power controls how tightly the glow hugs it.

Dissolve

Makes an object burn away, driven by a noise texture. Feed amount from 0 to 1 and it vanishes with a glowing edge.

shader_type spatial;

uniform sampler2D pattern : hint_default_white;
uniform float amount : hint_range(0.0, 1.0) = 0.5;
uniform vec4 edge_color : source_color = vec4(1.0, 0.4, 0.1, 1.0);
uniform float edge_width : hint_range(0.0, 0.2) = 0.05;

void fragment() {
	float mask = texture(pattern, UV).r;
	if (mask < amount) {
		discard;
	}
	ALBEDO = vec3(0.6);
	if (mask < amount + edge_width) {
		EMISSION = edge_color.rgb * 3.0;
	}
}

discard throws the pixel away entirely — not transparent, absent. For the pattern uniform, make a NoiseTexture2D in the Inspector; any greyscale image works.

The glowing edge only reads as glowing with glow enabled on the environment. Without it, EMISSION above 1.0 just clips to white.

Waves

The first four examples changed colour. This one moves geometry, which is what vertex() is for.

shader_type spatial;

uniform float wave_height = 0.2;
uniform float wave_speed = 1.5;
uniform float wave_length = 2.0;

void vertex() {
	VERTEX.y += sin(VERTEX.x / wave_length + TIME * wave_speed) * wave_height;
}

void fragment() {
	ALBEDO = vec3(0.15, 0.40, 0.70);
	ROUGHNESS = 0.1;
	METALLIC = 0.0;
}
A plane with four corners cannot wave. Vertices are the only places the shader can move, so the effect is only as smooth as the mesh is dense. Raise the subdivision on the PlaneMesh until it looks right. This also means physics and collision do not follow — the shape the player collides with stays flat.

Moving vertices leaves NORMAL pointing where it did before, so lighting will not follow the wave. Recomputing normals properly is more work than the wave itself; for gentle motion, nobody notices.

2D built-ins

The ones that come up in canvas_item shaders. Writable ones are marked.

NameStageMeaning
COLORfragment · writeThe pixel that ends up on screen. In vertex() it is the vertex colour instead.
UVbothPosition within the texture, 0 to 1.
TEXTUREfragmentThe node's own texture, ready to sample.
TEXTURE_PIXEL_SIZEbothThe size of one texel in UV units. Use it to step to a neighbour.
VERTEXvertex · writePosition in local space. Move it to distort the sprite.
SCREEN_UVfragmentPosition on the screen rather than on the sprite.
POINT_COORDfragmentCoordinate within a point primitive.
NORMAL, NORMAL_MAPfragmentSurface direction for 2D lighting; write NORMAL_MAP to feed one from a texture.
SCREEN_PIXEL_SIZEfragmentThe size of one screen pixel in SCREEN_UV units.
AT_LIGHT_PASSbothTrue while the object is being drawn for a light.
TIMEbothSeconds since the game started.

3D built-ins

A spatial fragment shader has sixty-one built-ins. These are the ones you will actually reach for.

NameStageMeaning
ALBEDOfragment · writeBase colour before lighting. The main output.
ALPHAfragment · writeTransparency. Writing it at all turns the material transparent.
METALLICfragment · write0 for everything that is not metal, 1 for bare metal. Values between are rarely right.
ROUGHNESSfragment · write0 is a mirror, 1 is chalk.
EMISSIONfragment · writeLight the surface gives off. Unaffected by lamps.
NORMALfragmentSurface direction in view space.
NORMAL_MAPfragment · writeWrite a sampled normal map here and the engine handles the rest.
VIEWfragmentDirection from the surface to the camera.
VERTEXboth · writePosition: local space in vertex(), view space in fragment().
UV, UV2bothTexture coordinates from the mesh.
AOfragment · writeBaked occlusion, darkening creases.
RIM, RIM_TINTfragment · writeBuilt-in rim lighting, if you would rather not compute it yourself.
SCREEN_UVfragmentWhere this pixel sits on screen.
FRONT_FACINGfragmentFalse on back faces. Useful with cull_disabled.
MODEL_MATRIXbothLocal space to world space, when an effect must be world-anchored.
