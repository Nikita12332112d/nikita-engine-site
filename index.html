What this is

A whole engine, and nothing in the way.

2D and 3D in one editor, a Vulkan renderer, physics, animation and exporters. No launcher to sit through, no account to make, and no store waiting in a tab.

Its own language

NikaScript keeps its vocabulary short: fn, let, from, embed. Indentation for scope, no semicolons, no build step. Files carry the .nika extension.

Its own editor

A violet accent, an N for a mark, and a background that drifts instead of sitting flat. The asset store is gone from both the editor and the project manager — nothing in the window is trying to sell you anything.

2D and 3D together

The same editor, the same scene tree and the same language for both. There is no separate 2D product, and no tier that unlocks the rest of the renderer.

The language

NikaScript

Indentation-scoped and dynamically typed, with optional type annotations where you want them. It compiles to bytecode, so scripts stay fast and reload the moment you save.

 player.nika
from CharacterBody3D

let bullet := embed("res://bullet.tscn")
let speed := 6.0
let health := 100

fn _physics_process(delta: float) -> void:
	velocity.z -= speed * delta
	move_and_slide()

	# react to whatever we ran into
	for i in get_slide_collision_count():
		let body := get_slide_collision(i).get_collider()
		if body.is_in_group("enemy"):
			body.take_damage(25)
		elif body.is_in_group("pickup"):
			health = min(health + 10, 100)

The editor

Quiet by default.

You look at the interface for hours at a stretch, so three things about it are deliberate.

A background that moves

A field of soft blobs drifts behind the whole interface — the same shader running behind this page. It costs one draw call and idles with the editor, so it never spins your fan.

Violet, not blue

The accent is #8B5CF6 across every panel, handle, and highlight, with the neutrals pulled slightly toward it so nothing reads as stock grey.

Nothing to buy

No asset store tab in the main bar, none in the project manager, and no online-connection warning where the button used to sit.

Getting it

Download and start.

One archive, no installer and no account. Unpack it wherever you like and run it — the editor and the runtime are the same file.

Download for Windows

Version 1.0.dev · 64-bit · 76.5 MB

Run it

Unpack the archive and start Nikita.exe. The project manager opens; press New and you are in the editor.

Add export templates

To turn a project into something you can hand to another person, open Editor → Manage Export Templates and press Download and Install. The editor fetches them itself.

No strings

No licence key, no account, no royalties and no seat count. Use it for anything, including work you sell.
